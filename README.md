# Social Media Platform

A full-stack social media web application built using Node.js, Express.js, MongoDB and frontend technologies.

## Features

- User registration and login
- Create and manage posts
- Upload images
- View posts
- Update and delete posts
- MongoDB database integration
- REST API based backend

## Technologies Used

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer

### Frontend
- HTML
- CSS
- JavaScript
